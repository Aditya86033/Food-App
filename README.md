# 🍔 Food Delivery App – Figma UI Design

## 📌 Overview

This project is a complete **Food Delivery Mobile App UI** designed using Figma.
It covers the full user journey — from onboarding and browsing food to placing orders and tracking deliveries — with a clean, modern, and user-friendly interface.

---

## 🎯 Features

* 🔍 Browse restaurants and food categories
* 🍕 View detailed menus and food items
* 🛒 Add items to cart
* 💳 Smooth checkout process
* 🚚 Real-time order tracking
* ⭐ Ratings and reviews
* 👤 User profile and order history

---
